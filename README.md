# Juan — Front-end Developer Portfolio

Public portfolio for **Juan**, Front-end Developer & Digital Designer based in São Paulo, Brazil.

**Live site:** https://juandrhc.github.io/

## About

A lightweight, responsive portfolio made using **HTML5, CSS3, and vanilla JavaScript** (no framework or build pipeline required). Includes accessible project filters and a Portuguese/English switch.

## Selected work

1. **StreetGO** — custom HTML/CSS/JS and WordPress front-end.
2. **Viva Drift** — browser game made with JavaScript, Three.js and Blender.
3. **Alife Nino** — WordPress redevelopment, dynamic pages and navigation.
4. **Obrabank** — client case study in preparation.
5. **SeMudando** — responsive web development.
6. **QR Code Generator** — private Flask/Python web application.
7. **Renault Koleos** — pre-reservation UI prototype.

## Files

- `index.html` — accessible semantic markup.
- `styles.css` — responsive styling, project illustrations, dark theme.
- `script.js` — PT/EN translations, project filtering and dynamic year.
- `favicon.svg` — brand mark.

## Run

Open `index.html` in your browser, or enable GitHub Pages for the `main` branch at `/(root)`.

## Notes

The project visuals are **conceptual CSS illustrations**, not screenshots of client websites. Proprietary client source code is not included. React and TypeScript are skills currently being learned.
